# VxFiles 2.2.1

## Fixes

- Right-clicking empty space in a folder opens a context menu with its actions again. Building the menu asked Windows whether the folder was pinned to Start, which VxFiles cannot answer, and the whole menu was abandoned. Right-clicking a folder or a program was affected the same way.
- Pin to Start and Unpin from Start now appear disabled instead of appearing to work. VxFiles cannot create Start menu tiles, and the commands no longer run from the command palette or a keyboard shortcut either.
- A context menu that cannot be built falls back to a few basic actions rather than opening empty, and the reason is written to the log instead of being discarded.
- The notification shown after an unexpected error appears again. Its Report button carried a link the notification could not encode, so the notification was dropped every time it mattered.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.
