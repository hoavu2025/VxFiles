# VxFiles 2.3.0

Upstream sync with Files Community (post-v4.2.1, commit 36b702f).

## Improvements

- Improved archive compression progress reporting — progress updates no longer dispatch to the UI thread per file, reducing overhead and improving responsiveness during large archive operations

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles 2.0.3+ installations will update automatically.
