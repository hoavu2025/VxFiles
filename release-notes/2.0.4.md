# VxFiles 2.0.4

## Changed

- No functional changes. This release exists to prove that VxFiles 2.0.3 and later install updates on their own.

If you are running 2.0.3, leave VxFiles open for a minute so this release can download in the background, then close and reopen it. About should report 2.0.4 without you clicking anything.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.
