# VxFiles 2.0.3

## Changed

- VxFiles now installs updates on its own. A newer release is downloaded quietly in the background and applied when you close the app, so the next launch is already up to date. The update button in the address bar still takes an update immediately instead of waiting.

## Upgrading from 2.0.1 or 2.0.2

Earlier versions only offered updates through the address-bar button and never installed one on their own, so this release has to be taken manually. Either click the update button in your installed VxFiles, or download and run `VxFilesApp-win-Setup.exe` below over your existing installation. Releases after this one will arrive automatically.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.
