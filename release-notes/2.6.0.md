# VxFiles 2.6.0

VxFiles has always updated itself quietly and still does. What changes is that it now tells you an update is waiting, and lets you take it without waiting for your next restart.

## Features

- **A dot on the Settings icon** in the sidebar appears once a new version has been downloaded and is waiting. Clicking it opens Settings straight to About.
- **An update card at the top of the About page** names the version that is waiting, shows what changed in it, and offers a **Restart to update** button. It also carries a **Check for updates** button for anyone who would rather not wait for the hourly check.
- **The last successful check is shown**, and it only moves when a check actually reached GitHub. An updater that has quietly stopped working now says so instead of looking healthy.
- **VxFiles re-checks once an hour while it runs**, not only at launch.

None of this gates anything. An update you never look at still installs the next time you close VxFiles, exactly as before. The card only decides *when*.

## Fixes

- **Restarting to update no longer kills work in progress.** Taking an update immediately used to terminate the process outright: a large copy or move died mid-write, leaving a partial file at the destination with nothing to undo it, and open tabs were lost. The restart now shuts VxFiles down properly — file operations finish, running automations are cancelled, and your tabs come back.
- **A failed update check no longer discards an update that was already downloaded.** Losing your network after an update had been fetched would throw the fetched release away, and the next check had to download the whole thing again.

## Notes

The update card is absent when VxFiles was not installed by its own installer — a copied or unzipped build has nothing to update.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles 2.0.3+ installations will update automatically.
