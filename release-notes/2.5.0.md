# VxFiles 2.5.0

Two fixes that only ever showed up in the installed app, so neither was visible when running VxFiles from a development build.

## Fixes

- Icons appear throughout the installed app again. Almost none of the app's images were being included when the release was built, so anything drawn from a bundled image was simply blank: the section icons in the sidebar, folder and archive icons, and the shelf and WSL icons. Nothing failed loudly, which is why an otherwise healthy-looking build shipped without them.
- Creating a new file or folder shows the name box again. The dialog opened with its title and its Create and Cancel buttons but nothing in between, so there was no way to type a name. The same empty-body problem affected other dialogs built the same way.

## Notes

This release is numbered 2.5.0 rather than 2.4.1 because the fork inherits Files Community's original version tags, and `v2.4.1` through `v2.4.71` are already taken by upstream releases from 2022. Nothing about the app changes as a result.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles 2.0.3+ installations will update automatically.
