# VxFiles 2.1.0

Upstream sync with Files Community v4.2.1 (upstream releases v4.0.38 through v4.2.1).

## New Features

- Customizable toolbar — rearrange, add, and remove toolbar buttons
- Search settings — find settings quickly with a new search box
- Auto-fit columns — a new setting and action to automatically size columns to fit content
- Open current folder in other pane — new action to mirror the current folder in a split pane
- Sidebar section icons — updated icons for Home, Drives, and Cloud Drives sections
- Skip and Skip All buttons in the File In Use dialog
- Path hints for tabs with the same name
- AVI file preview support in the Preview Pane
- Font picker in Appearance settings
- Edit Tags button in toolbar
- Keyboard shortcut support for changing the app theme
- Media duration shown in tooltips
- Selection checkbox in Details Layout header
- Multiline support for the comment property in the Properties Window
- Scroll wheel cycles through layouts
- Tab dragging to create a new pane
- Access key support for shell extensions
- Network Discovery banner when discovery is turned off
- Open With flyout in the toolbar
- Rename keeps sort order until refresh
- Inline banner replaces the "folder not found" dialog
- Prompt when there is an issue compressing a file
- Improved messaging when failing to pull from Git
- Improved behavior when opening encrypted archives
- Improved startup behavior when continuing where you left off

## Under the Hood

- Upgraded Windows App SDK from 1.8 to 2.3.1
- Refactored Git integration as a DI service
- Replaced raw ABI pointers with ComObject instances for safer disposal
- Improved folder loading performance
- Optimized selection rectangle performance
- Sidebar group expansion state is now persisted
- Settings moved from dialog to a full page
- Separate mouse and touch settings for single-click behavior
- Thumbnail cache settings UI
- Sidebar control implemented in Properties Window

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles 2.0.3+ installations will update automatically.
