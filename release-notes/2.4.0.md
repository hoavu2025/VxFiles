# VxFiles 2.4.0

Upstream sync with Files Community (post-v4.2.1, through commit af991c3).

## New Features

- Remember the last used folder in the background image picker
- Fixed issue where the Customize tab was hidden for network folders that support custom icons

## Improvements

- Enabled WinUI XAML optional performance optimizations (style, icon, and context flyout init)
- Moved file tags database reconciliation off the startup path for faster launch
- Bumped Microsoft.Windows.SDK.BuildTools to 10.0.28000.2526

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles 2.0.3+ installations will update automatically.
