# Limit VxFiles renaming to the public identity

Use VxFiles for public product, package, publisher, executable, protocol, alias, window, splash, startup task, startup error, distribution, and fork-owned link identity.

Retain inherited `Files.*` namespaces, projects, libraries, solution structure, application id, extension names, background entry points, COM identities, task identifiers, and persistence identifiers. Reuse the Files Dev icon assets byte-for-byte in V1.

This seam distinguishes the installed fork without creating pervasive rename conflicts during future Files stable-tag merges.
