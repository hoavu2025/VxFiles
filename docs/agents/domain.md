# Domain documentation

VxFiles is a single-context repository.

Before exploring or changing a domain area:

- read the root `CONTEXT.md`;
- read relevant decisions under `docs/adr/`;
- use the glossary terms from `CONTEXT.md` in issues, plans, tests, and implementation;
- surface any conflict with an existing ADR explicitly.

If a needed term is absent, do not silently invent competing vocabulary. Record the gap for domain modeling when it affects a design decision.
